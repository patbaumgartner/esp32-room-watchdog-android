## Conventions

- File names follow `NNNN-kebab-case-title.md`.
- New decisions start as `Proposed`, become `Accepted`, and are later `Superseded by ADR-XXXX` — never deleted.
- Keep the ADR to one decision; revisit by superseding, not editing in place.
